| # | 심각도 | 내용 | 처리 |

## 4. 수정 후 확인 (직접 재현)

- 홈 새로고침 → [운동 시작] → [시작]: 세트 진행 화면 유지, 세트 완료와 휴식 타이머 정상 (수정 전에는 홈으로 되돌아감)
- 운동 도중 새로고침: 홈으로 이동, 진행 정보 삭제, 완료한 1세트 기록 유지
- 진행 정보가 남은 채 `/workout/session` 직접 입력: 홈으로 이동
- 결과 저장 실패 상태에서 [운동 종료] 후 [재시도] 두 번: 기록 1건 그대로 (새 세트 미추가), 저장이 가능해지면 결과 화면으로 이동
- 깨진 기록 데이터: 홈·기록·추세에 오류 문구가 나오고 `아직 운동 기록이 없습니다`와 내보내기 버튼은 나오지 않음. 저장소를 비우면 정상 문구로 돌아옴
- 자동 테스트 57건 통과 (진입 표시 3건 추가), `npm run build` 통과, 콘솔 오류 없음
